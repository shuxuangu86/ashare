# v0.3 可信微盘基准协议

`microcap-400-p0` 是研究基准，不声称复刻任何官方指数。它的任务是固定一个透明、
可归因、可成交的微盘 Beta，后续增强策略必须在相同数据、股票池和成本假设下与它比较。

400 只截面用于定义 Beta。对 100 万元账户，400 只按 100 股一手真实等权通常不可执行；
若任一目标不足一手，事件驱动执行会失败，不会悄悄丢弃这些股票。后续 95 只版本用于
研究较小资金下的可执行实现，两者必须分别报告，不能把 95 只收益冒充 400 只基准。

## 信号与数据边界

- 每个调仓日必须提供显式 `asof_time` 的 PIT 截面；
- 截面中任一记录的 `available_at` 晚于 `asof_time` 时整次运行失败；
- 排名使用 T 日已知总市值，订单最早在 T+1 开盘撮合；
- 调仓日期由交易日历预先生成，不在策略内部用自然日猜测；
- 缺少截面、成分数量不足或成分缺少行情时失败，不缩小样本继续运行。

## 股票池

默认从沪深 A 股中选择总市值最小的 400 只，并排除：

- 上市不足 120 个自然日；
- ST；
- 当日停牌；
- 非沪深交易所证券。

每次选择保存各排除原因的数量。市值相同时用规范证券代码排序，保证结果可复现。

## 组合与成交

- 成分股等权，默认保留 2% 现金；
- 目标股数按 T 日收盘价向下取整至 100 股；
- 卖单排在买单之前；
- 使用 A 股规则撮合：费用、印花税、滑点、成交量上限、停牌与涨跌停；
- 基准使用 `CANCEL_AFTER_OPEN` 日订单策略，T+1 未成交余额不会在后续日期意外成交。
- 任一等权目标不足 100 股时整次执行失败，并提示降低成分数或提高资本。
