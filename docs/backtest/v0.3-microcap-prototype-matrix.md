# v0.3 微盘六原型实验协议

本实验先回答两个问题：

1. 微盘收益主要来自最小100只，还是广泛存在于第101—400只？
2. 研究Beta扣除A股成交约束后，100万元账户可以保留多少可得收益？

当前版本完成实验协议、选择器、调仓日历、成本场景、事件驱动运行器和合成市场验收。
真实历史收益尚未生成；在数据发布恢复前，任何合成结果都不得表述为策略收益。

## 六个原型

| 原型 | 规则 | 资金口径 |
| --- | --- | ---: |
| `smallest-100` | 合格股票按总市值升序的前100只 | 1亿元研究资金 |
| `rank-101-400` | 合格股票按总市值升序的第101—400只 | 1亿元研究资金 |
| `smallest-400` | 合格股票按总市值升序的前400只 | 1亿元研究资金 |
| `executable-95` | `PB>0`且净利润同比增长为正，按总市值选95只；持仓跌出120名才卖 | 100万元 |
| `dividend-quality-10` | 股息率最高一半→资产负债率最低一半→20日换手波动最低一半→流通市值最小10只 | 100万元 |
| `low-pb-low-turnover-35` | 正PB中最低一半→20日换手波动最低一半→总市值最小35只 | 100万元 |

六个原型统一排除非沪深证券、上市不足120日、ST、退市风险和停牌证券。默认至少需要
400只基础合格证券。95/10/35只原型不会因为因子缺失而自动缩小目标数；可用截面不足时
整次运行失败。

## PIT与执行时序

- 组合观测的 `available_at` 必须是所有已填字段可得时间的最大值；
- 任一字段晚于T日信号时间时，`MicrocapSnapshot` 拒绝该截面；
- T日收盘形成目标，最早T+1开盘成交；
- 周频选择完整交易周的最后一个交易日，月频选择完整月份的最后一个交易日；
- 回测末日不生成无法在下一交易日成交的悬空信号；
- 普通再平衡按日/周/月频率运行，ST与退市风险硬退出每天运行；
- 重大事件、收益透支和风格择时不进入首轮六原型，避免污染选股归因。

## 72格矩阵

六个原型分别运行日频、周频、月频，并输出四档摩擦：

1. `frictionless`：下一开盘价成交，不施加市场规则或费用；
2. `rules-only`：100股整数手、停牌/涨跌停、0.5%前20日平均成交量容量上限，费用与滑点为零；
3. `base-cost`：交易规则加5bp滑点、佣金、印花税和过户费；
4. `double-cost`：基础场景的滑点与全部费用乘以2。

规则成本场景只允许使用交易前已知的 `prior_20d_average_volume`。缺失时订单不成交；
严禁回退到T+1全天成交量，因为那会在开盘引入未来信息。

基础费率从2015年7月9日起支持历史版本：过户费在2022年4月29日调整，印花税在
2023年8月28日调整。更早的费率结构存在交易所差异，当前实现会停止运行，不能用今天
的费率回填。2023年印花税调整依据
[财政部、税务总局公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html)；
交易规则或费用表扩展后必须新增生效日边界测试。

## 验收输出

统一报告至少保存：

- 总收益、最大回撤、成交率、交易额/初始资金、总费用；
- 每个原型相对同频率、同成本场景 `smallest-400` 的超额；
- 100万元组合的现金占用、一手不足数量、未成交和容量受限数量；
- 分年度收益、滚动三年超额胜率与成本压力敏感度；
- 数据发布ID、代码版本、配置哈希和最终状态哈希。

当前 `render_microcap_matrix_report` 已提供第一层组合表。分年度、滚动三年和数据发布绑定
将在真实PIT加载器接入时生成，不能从合成市场推断。
