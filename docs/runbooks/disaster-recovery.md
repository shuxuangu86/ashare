# 故障恢复手册

| 故障 | 默认动作 | 恢复条件 |
| --- | --- | --- |
| 数据源空表/字段变化 | 数据版本隔离，不发布 | 修复 Adapter 并重跑全批次质量检查 |
| PostgreSQL/Redis 中断 | 停止新任务和订单 | 数据库恢复、审计完整、券商核对通过 |
| 券商连接中断 | UNKNOWN，不猜测失败 | 主动查询订单、成交和账户后恢复 |
| 执行代理重启 | 读取持久订单状态和幂等索引 | 与券商核对一致后继续 |
| 重复/乱序回调 | 去重、归档、不回退状态 | 无需人工，异常计数进入报告 |
| 行情过期 | Kill Switch | 新行情连续健康并人工复位 |
| 磁盘空间不足 | 停止数据发布和新实验 | 扩容、校验已有文件 SHA-256 |
| 系统时间异常 | 停止所有自动交易 | NTP 恢复、事件时钟和券商时间核对 |

## 恢复顺序

1. 保持 Kill Switch 激活；
2. 恢复数据库和不可变数据文件；
3. 校验最近发布版本、订单审计和文件哈希；
4. 从券商重新拉取账户、订单与成交；
5. 用券商真相修正本地派生状态，不修改原始审计事件；
6. 运行核对、风险和健康检查；
7. 人工确认后复位 Kill Switch。
