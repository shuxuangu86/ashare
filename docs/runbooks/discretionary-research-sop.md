# 主观基本面策略研究与审批 SOP

## 每日盘后

1. 运行价格与经营异常雷达，异常只进入候选池。
2. 对新增证据保存原始 URI、内容哈希、方法版本及四个时间戳。
3. 确认来源取得方式为公开、授权或合规调研。
4. 标记依赖簇，检查是否只是同一原始消息的转载。
5. 同时写出证据对基本面、资金/技术和噪声三类假设的影响。
6. 明确反证出现时立即触发持仓复核，不等待例行调仓。

## 每周研究会

对每个候选与持仓逐项回答：

- 我们现在知道什么，哪些仍是推断？
- 市场现在相信什么，依据是什么？
- 下一条会显著改变概率的证据是什么，何时出现？
- 三个关键变量是否仍然足以解释价值？
- 因果链的哪一环最脆弱？
- 新证据是否来自真正独立的来源簇？
- 如果当前没有持仓，是否仍愿意以现价买入相同权重？

系统重算实时后验、证据阶段和仓位建议。研究员检查原始证据与反方解释后，才能人工批准
等于或低于建议值的权重。全部现有持仓必须逐一重新审批。

## 财报与经营结果公布后

1. 测量账：记录非标指标是否预测对经营事实。
2. 传导账：记录需求、份额、收入、利润率和现金流在哪一环兑现或断裂。
3. 投资账：记录判断相对市场预期是否形成成本后超额收益。
4. 只用截至当时已公布的结果更新未来来源权重。
5. 生成回顾性平滑版本，但不得覆盖实时快照。
6. 把错误模式、有效结构和可迁移指标写入失败库或知识候选库。

## 强制停止条件

- 原始来源无法保留或取得方式不合规；
- 证据可用时间不明确；
- 三类竞争假设没有同时维护；
- 重大反证未处理；
- 市场隐含预期没有依据；
- 建议由回顾性数据产生；
- 加仓没有经营证据升级；
- 人工审批缺失、过期或审批权重超过建议；
- 数据发布、全局风控、核对或 Kill Switch 任一门禁失败。
