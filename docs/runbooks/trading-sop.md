# 模拟盘与实盘交易 SOP

## 盘前

1. 确认当日数据发布状态为 `PUBLISHED`，质量报告无 ERROR；
2. 确认策略、因子、模型、配置和代码版本与审批记录一致；
3. 从券商查询资金、持仓、订单和成交，并完成本地核对；
4. 确认行情时间、风险服务、执行代理和 Kill Switch 健康；
5. 生成目标仓位与订单计划，人工检查总金额、个股、行业和换手；
6. PAPER 默认可运行；LIVE 还需配置开关和当日人工确认。

任何一项失败都取消当日自动交易，禁止临时修改数据绕过门禁。

## 盘中

- 执行代理只读取 APPROVED 订单；
- UNKNOWN 订单停止自动重试，先向券商查询；
- 行情过期、连接中断、未知订单或回撤超限立即触发 Kill Switch；
- Kill Switch 激活后禁止新订单，并尝试撤销仍可撤订单；
- 重复和乱序回调写入事件日志，但不得让订单状态倒退。

## 盘后

1. 重新查询券商资金、持仓、订单和成交；
2. 逐项核对本地状态，券商状态作为最终真相；
3. 保存差异、处理过程、人工操作和审计哈希；
4. 生成成交成本、目标偏离和当日收益报告；
5. 未解决差异会阻止下一交易日开盘。
