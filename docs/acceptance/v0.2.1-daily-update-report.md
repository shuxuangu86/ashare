## 已验证不变量

- 收盘后只创建 19:30 一次正式任务，不存在 17:20 任务。
- 次日 08:30 不读取当日未收盘行情，只重查最近三个已完成交易日。
- 两档任务检查点隔离，同一档重复运行可续传，全局锁拒绝重叠实例。
- 4 个工作线程共享全局 0.25 秒最短请求间隔。
- 核心行情、交易状态、指数或四张财务数据请求失败时不发布数据版本。
- 预期非空的核心数据返回空集、错误交易日、重复主键或非法 OHLCV 时不发布。
- 日线 Parquet 保存所有来源 Raw batch ID；Raw 响应及接收时间不可变。
- 可选接口失败进入质量警告，不会被静默当作完整数据。
- 成功运行发布新的 `cn_equity_YYYYMMDD_NNN`，失败版本只进入 quarantine。
- 上交所、深交所和北交所代码分别标准化为 `XSHG`、`XSHE`、`XBSE`。
- Windows 安装脚本启用唤醒、错过补跑、15 分钟失败重试和 IgnoreNew。
