## 已证明的不变量

- 正式研究案必须包含三类竞争假设、完整因果链、三个关键变量与交叉来源；
- 所有证据按 `available_at` 进行 PIT 截断，未来证据和未来后验不可见；
- 同一依赖簇内的重复证据不会重复增加概率；
- 价格证据单独存在时，建议仓位严格为 0；
- `RETROSPECTIVE` 判断不能生成仓位建议；
- 观察、证据、核心阶段分别受 0.5%、2%、5% 默认上限约束；
- 已有持仓缺少新证据升级时不能加仓；
- 明确反证触发 0 权重退出建议；
- 人工审批只能批准等于或低于建议的权重；
- 任一既有主观持仓没有当期人工复核，目标组合生成失败关闭；
- 获批仓位能够进入标准 `TargetPortfolio` 和既有 `RebalancePlanner`，不绕过订单链路；
- 知识候选必须经历发现、复现、验证、影子和人工批准才能进入生产；
- 被否决候选必须保留失败原因。
