系统默认 `BACKTEST`，所有券商配置的 `live_submission_enabled` 均为 `false`，且 MVP 拒绝
`LIVE_FULL`。

## 尚未通过的外部验收

以下事项依赖目标电脑、网络、供应商或券商，本环境没有伪装成已完成：

1. Docker 不可用，因此 PostgreSQL、Redis、Prefect 和 MLflow 未实际启动。
2. 免费数据源未执行真实在线拉取；上游字段变化、限流和历史覆盖仍需烟雾测试。
3. PostgreSQL migration 仅通过挂载与内容检查，尚未在真实容器事务中执行。
4. QMT / XtQuant SDK、终端和模拟账户尚未连接；当前只验证可注入适配边界。
5. 尚未连续运行五个真实交易日，因此稳定性最终门槛未完成。
6. 所有收益相关测试均为合成市场或算法测试，不证明任何真实策略有收益。

## 上机验收顺序

1. 安装 Git、WSL2、Docker Desktop、Python 3.11 和 uv。
2. 从发布包恢复仓库，复制 `.env.example` 为 `.env` 并修改本地密码。
3. 执行 `make bootstrap`、`make quality` 和 `make infra-config`。
4. 启动基础服务，确认两组 migration 成功且健康检查全部通过。
5. 只拉取少量股票和日期进行免费源烟雾测试，核对 Raw 哈希与 Standard Schema。
6. 发布首个真实数据版本；任何差异超阈值必须进入 quarantine。
7. 在 `PAPER` 模式连续运行至少五个交易日，并每日核对资金、持仓、订单与成交。
8. 获得券商环境后仅启用 `LIVE_READ_ONLY` 完成查询和回调联调。

## 发布决定

可以冻结为 `v0.1.0-mvp` 代码候选；不得启用真实下单。完成上述外部验收并清零 P0/P1
缺陷后，才可讨论小资金阶段。
